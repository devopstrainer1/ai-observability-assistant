# AI Observability Assistant

This repository is a concise case study of an "AI Observability Assistant" — a weekend project demonstrating product thinking and implementation details for monitoring and debugging AI systems. It contains a small Node.js service that simulates telemetry ingestion, alerting rules evaluation, and a demo UI to visualize incidents.

Contents

- DECISIONS.md — design decisions, approach, and tradeoffs
- case-study.md — narrative and screenshots
- LICENSE — MIT

- src/ — simple Express.js + React demo
- submission/ — sample screenshots

Quick start

1. Install dependencies

   npm install

2. Run server

   npm run dev

3. Open UI

   http://localhost:3000
